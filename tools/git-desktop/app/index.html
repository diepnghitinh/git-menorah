Empty canvas

Open an agent to get started. Every node is a real terminal: type as you would in the CLI, or switch to Chat.

  • Drag the background or scroll with two fingers to pan, ⌘ + scroll to zoom
  • Right-click the background to add an agent, terminal or note right there
  • Drag a node corner to resize, double-click the title to rename
  • Drag the link dot in a title bar onto another node so agents can read each other’s context
  • Drop files or images into a terminal to hand their paths to the agent; paste images with ⌘V
